# TecFlow

O **TecFlow** é um sistema de gerenciamento de assistência técnica.

## Sobre o projeto

O TecFlow é uma aplicação web desenvolvida com **Python e Django**, com o objetivo de proporcionar maior organização, praticidade e eficiência na administração de assistências técnicas.

O sistema busca simplificar processos administrativos e operacionais por meio de uma interface intuitiva, permitindo que as informações sejam gerenciadas de maneira centralizada.

O projeto é desenvolvido em equipe, aplicando conceitos de desenvolvimento web, programação, banco de dados e engenharia de software.

##  Objetivo

Desenvolver uma plataforma web capaz de auxiliar no controle e gerenciamento dos serviços de uma assistência técnica, facilitando o acompanhamento das atividades, a organização dos registros e a administração das informações.

## ⚙️ Módulos do sistema

###  Clientes
Módulo destinado ao cadastro, consulta e gerenciamento das informações dos clientes da assistência técnica.

###  Equipamentos
Área responsável pelo registro e organização dos equipamentos recebidos dos clientes para manutenção.

###  Ordens de Serviço
Permite organizar e acompanhar as ordens de serviço, incluindo informações sobre diagnósticos, reparos e andamento dos atendimentos.

###  Pagamentos
Área destinada ao controle e à organização dos pagamentos relacionados aos serviços prestados.

###  Técnicos
Módulo destinado ao gerenciamento da equipe técnica e suas especialidades.
